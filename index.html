📲 Pasang sebagai Aplikasi

🤖 Android (Chrome)
  1. Buka link ini di Chrome.
  2. Tekan tombol Install di bawah, atau menu ⋮ → Instal aplikasi.
  3. Ikon mesin cuci muncul di layar HP.
🍎 iPhone (Safari)
  1. Buka link ini di Safari.
  2. Tekan tombol Bagikan.
  3. Pilih Tambahkan ke Layar Utama → Tambah.
💻 Laptop
  1. Klik ikon install di ujung kanan kolom alamat Chrome/Edge.
  2. Klik Instal.
Satu hari hanya satu orang yang bertugas, biar yang lain bisa istirahat 💙
